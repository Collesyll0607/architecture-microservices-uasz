Ce dossier a été spécialement agencé pour vous permettre d'exécuter l'ensemble
de l'écosystème microservices en 1 seul clic, sans aucune manipulation complexe.

--------------------------------------------------------------------------------
1. ORGANISATION DU DOSSIER
--------------------------------------------------------------------------------
├── 01_RAPPORT_ET_COMPTE_RENDU/   -> Le compte-rendu officiel (Word .docx et PDF HD)
├── 02_MICROSERVICES_SOURCE/      -> Code source des 5 microservices et parent pom.xml
├── 03_BASE_DE_DONNEES/           -> Script d'initialisation SQL complet (UTF-8)
├── 04_SCRIPTS_EXECUTION/         -> Scripts de lancement automatique 1-clic (.bat et .sh)

├── docker-compose-xampp.yml      -> Variante si vous utilisez le MySQL de XAMPP
└── README.md                     -> Documentation technique détaillée

--------------------------------------------------------------------------------
2. COMMENT DÉMARRER LE PROJET ? (DEUX MÉTHODES AU CHOIX)
--------------------------------------------------------------------------------

MÉTHODE A : DÉMARRAGE 1-CLIC AVEC DOCKER (RECOMMANDÉ - ZÉRO CONFIGURATION REQUISE)
  1. Ouvrez le dossier "04_SCRIPTS_EXECUTION".
  2. Double-cliquez sur "1-DEMARRER-DOCKER.bat".
  -> Le script compile et lance automatiquement le conteneur MySQL et les
     5 microservices, puis ouvre votre navigateur sur http://localhost:8080 !

  (Si vous préférez la ligne de commande, ouvrez un terminal à la racine et tapez :
   docker compose up --build -d)

MÉTHODE B : SI VOUS PRÉFÉREZ UTILISER VOTRE XAMPP MYSQL LOCAL (PORT 3306)
  1. Lancez MySQL dans XAMPP et importez le fichier :
     03_BASE_DE_DONNEES/init_clean_utf8_data.sql dans une base nommée "patrimoinedb".
  2. Dans un terminal à la racine, tapez :
     docker compose -f docker-compose-xampp.yml up --build -d
